<a id="selection"></a>

## Selection and source of truth

This is a filtered view of FastPrep's production Firestore `problem` collection, refreshed on **July 31, 2026**. It contains only public, published problem documents whose canonical `company` value exactly matches the tracked-firm allowlist in [`assets/company-domains.json`](assets/company-domains.json). Public titles and route aliases are copied without rewriting; **Last seen** is the newest ISO date in the document's `lastSeen` array.

FastPrep currently has no quant-specific target role or topic. Its target-role enum covers software engineering and data roles, so it cannot prove that an individual question was used for a quant trader or quant researcher position. This tracker therefore makes the narrower, supportable claim: these are question-bank items attributed to firms whose core business is quantitative/systematic/proprietary trading or investment management. Broad banks, fintechs, and diversified asset managers are excluded to avoid pretending that company affiliation is role evidence.

Only public-safe metadata appears here: firm, title, public problem URL, and latest sighting date. Answers, editorials, hidden tests, evaluator content, full private source statements, and restricted problems are never included.
